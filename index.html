Learning to name what you hear before you see it.

  1. Major vs. minorSet up →
    Check only Major and Minor under Triad, name which one before revealing.
  2. Add diminished and augmentedSet up →
    All four Triad qualities on — name the quality by ear each time.
  3. Triad vs. seventhSet up →
    Compare "None (bare triad)" against Major 7th on the same quality; hear exactly what the 7th adds.
  4. Major 7 vs. dominant 7Set up →
    The two "consonant-ish" sevenths that trip people up most — isolate just these two.
  5. Diminished vs. augmentedSet up →
    Both have a tense, unresolved quality that's easy to mix up on their own — compare them side by side instead of isolating just one.
  6. Sixth vs. minor's dominant 7thSet up →
    6th and a minor triad's dom7 sound deceptively close — isolate and compare them back to back.
  7. Sus chords, no tensionsSet up →
    Sus2 and Sus4 only. Learn to hear "no third" before adding anything on top of it.
  8. Every seventh quality at onceSet up →
    All five Seventh/Sixth boxes on, one triad quality — name the seventh type on the fly.
  9. Full quality gauntletSet up →
    Every Triad and every Seventh/Sixth box on, nothing else — call the full quality (not the root) before revealing.
  10. Call the intervals, not the notesSet up →
    After naming the quality by ear, spell it as root-3rd-5th(-7th) intervals before you check — that's the learnable version of "spelling" a chord, no perfect pitch required.

Pitch recognition, not just color recognition.

  1. Name the rootSet up →
    Peek the first chord to set a reference pitch, then judge each new root relative to that anchor before checking — reference-based guessing, not absolute pitch.
  2. Root motion by intervalSet up →
    Four roots spanning uneven distances (C, Db, E, G) — name the actual size and direction of the jump each time, not a coin flip between two known options. Add more roots to the pool for a harder version once this feels easy.
  3. Inversions, spottedSet up →
    Turn on "Allow inversions and slash chords" and identify root position vs. inverted before revealing.
  4. Bass note vs. chord toneSet up →
    With slash chords on, sing the bass note separately from the quality sitting above it, then check whether it was an inverted chord tone or a true slash bass — you're isolating register and relationship, not naming absolute pitches.
  5. Slash-chord spellingSet up →
    Figure out which chord tone is in the bass — 3rd? 5th? 7th? — before Show Chords confirms it.
  6. Freeze and sing the rootSet up →
    Hit Freeze mid-drone, sing the root from memory, then Show Chords to check yourself.
  7. Freeze and sing the chordSet up →
    Same idea, but sing root–3rd–5th(–7th) as an arpeggio before checking.
  8. Back-and-forth interval drillSet up →
    Use ← Back / Next → to bounce between two roots repeatedly until that interval is automatic both directions.

How chords actually move in real tunes.

  1. ii-V motion, roughlySet up →
    Check Minor and Dominant, Circle of Fifths — you'll get a real mix of ii-type and V-type qualities moving by fifths, though it won't strictly alternate ii-V-ii-V the way an actual progression would.
  2. Full cycle of fifthsSet up →
    Let a whole 12-root cycle run uninterrupted. Worth naming honestly: with one quality checked, this is a transposition drill — the same shape moved everywhere — not functional harmony, since nothing about the quality itself ever changes.
  3. Cycle of fourthsSet up →
    Same transposition drill on Circle of Fourths — fourths is the direction real tunes actually resolve in, but one static quality moving through it still isn't functional harmony on its own.
  4. Static root, changing qualitySet up →
    One root, multiple qualities checked — hear color change with the key center held still.
  5. Two-root key-center drillSet up →
    Clear down to two roots a 5th apart, one quality, and treat it like a I–V pair to internalize.
  6. Chromatic root motionSet up →
    All 12 roots, Step Up Selected — a genuine chromatic run through every half-step, not two roots ping-ponging. Try Step Down too, or narrow the roots for a shorter run.
  7. Whole-tone root motionSet up →
    The six-note whole-tone set (C, D, E, Gb, Ab, Bb), Step Up Selected — a real ascending whole-tone run, a less common motion that's still worth owning.
  8. Cycle plus a tensionSet up →
    Circle of Fifths with one tension always on — hear how the same color feels as the function keeps changing.
  9. Fifths vs. fourths, comparedSet up →
    Run the same quality through both cycles back to back — it's the same set of roots, felt in opposite directions.

Using the drone as a practice rhythm section.

  1. Comp one static qualitySet up →
    One root, one quality, Metronome mode — comp rhythm patterns against a real pulse with zero harmonic changes to track.
  2. Comp changing roots, same qualitySet up →
    ALL roots, one quality — focus entirely on voice-leading between changes.
  3. Comp changing qualities, same rootSet up →
    One root, multiple qualities — isolate how a voicing's shape changes under a fixed root.
  4. Metronome-locked compingSet up →
    Duration Mode: Metronome, pick a Bars count, and comp in strict time instead of an arbitrary timer.
  5. Slash-chord compingSet up →
    Only inversions and slash chords on — voice the correct bass note under every single comp, not just the upper structure.
  6. Determine the chord qualitySet up →
    Use your instrument to help you work it out — play notes, test intervals against what you hear, whatever gets you there — before checking against the reveal.
  7. Comping with restraintSet up →
    Comp as if there's a singer or horn player who needs room — play less than feels natural, and notice how little harmonic information you actually need to state.
  8. Rootless voicingsSet up →
    For every chord, deliberately leave the root out of your voicing since the drone already states it.
  9. One voicing, every rootSet up →
    Pick a single voicing shape and see how far around the cycle you can carry it before it stops working.

Melodic practice with a moving (or static) target.

  1. One chord, one scaleSet up →
    Static vamp, matching scale only, nothing chromatic — until it's fluent.
  2. One chord, arpeggios onlySet up →
    Same static setup, restricted to arpeggiating the chord tones.
  3. Target the 3rd and 7thSet up →
    Turns on the Next-chord preview — check it as each chord starts, work out its 3rd and 7th, then land your first note there right as the next change hits.
  4. Motif developmentSet up →
    Play a 3–4 note idea, then let it evolve as the chord changes underneath it.
  5. Call and response with yourselfSet up →
    Play a phrase, leave space, answer it as the next chord arrives.
  6. EnclosuresSet up →
    Next-chord preview on — approach the upcoming target note by half-step above and below, landing on it right as the chord actually changes.
  7. Outside and backSet up →
    Over a locked static chord, deliberately play a half-step outside and resolve back in.
  8. Rhythmic displacementSet up →
    Play the exact same lick, but start it on a different beat every time the chord changes.
  9. Space and silenceSet up →
    Solo with more rests than notes — let the chord changes do some of the work for you.

Drill mechanics over a held chord, so the pattern stays tied to real harmony instead of abstract finger motion. These are self-paced — clicking one Starts the drone already frozen on a chord; move it with Next → when you're ready.

  1. Scale patterns, static chordSet up →
    Thirds, fourths, whatever pattern you're drilling — the held chord keeps every note honest about whether it's a chord tone or a tension.
  2. Arpeggio speed buildsSet up →
    One held chord — gradually raise your own tempo running the arpeggio until it's clean at speed.
  3. Position shiftingSet up →
    Play the held chord's scale or arpeggio in every position on the neck, then move the chord and do it again.
  4. String-skipping patternsSet up →
    Drill string-skipping over a held chord — the harmony underneath keeps the pattern musical instead of a blind finger exercise.
  5. Alternate picking to the clickSet up →
    Metronome mode at a fast tempo, held chord — drill clean alternate picking locked to the click.
  6. Legato runsSet up →
    Hammer-ons and pull-offs instead of picking — work a run over the held chord until it's even and smooth, then move on.
  7. Sweep-picked arpeggiosSet up →
    Held chord — drill a sweep shape that matches that exact quality until the pick hand tracks it cleanly.
  8. Full-neck arpeggio mappingSet up →
    One held chord — find and play every occurrence of the arpeggio across the whole fretboard before moving on.
  9. Endurance sheddingSet up →
    One chord, very long auto-advance — play continuously through fatigue the way you would in a real long solo section (don't freeze this one).

Using Duration Mode, BPM, and Bars on purpose.

  1. Metronome mode basicsSet up →
    Switch Duration Mode to Metronome — feel changes land on the barline instead of a countdown.
  2. Slow-tempo controlSet up →
    Low BPM, long Bars count per chord — plenty of time to choose notes deliberately.
  3. Fast-tempo reactionSet up →
    High BPM, short Bars count, Keys sound so each chord lands the instant it changes — force quick harmonic reactions.
  4. Odd bar groupingsSet up →
    Set Bars to 3 or 5 instead of 4 — practice phrasing that doesn't fall into default 4-bar habits.
  5. Tempo rampSet up →
    Raise the BPM every few minutes on the same material, building real speed gradually.
  6. Subdivided compingSet up →
    Metronome mode — comp one specific subdivision (straight 8ths, triplets) consistently through every change.
  7. Anticipation practiceSet up →
    Next-chord preview on — land the upcoming chord's target note a hair before the change actually lands, jazz-style anticipation.
  8. Staying interesting on one chordSet up →
    How long can you keep things interesting on just one chord?
  9. Polyrhythmic phrasingSet up →
    Over a static chord in Metronome mode, deliberately phrase in groups of 3 against the 4-feel click.
  10. Just listenSet up →
    Play nothing — just listen and absorb the sound and feeling of the chord.

Tensions and altered color, isolated and combined.

  1. One tension at a timeSet up →
    Check just b9 over a dominant chord, nothing else, and sit with that one color — sing the tension against the chord, find it on your instrument, learn its specific bite. Then swap it for natural 9, then #9, absorbing each on its own before you'd ever try to tell them apart by ear.
  2. Natural vs. altered 9thSet up →
    A/B compare "9" against "b9" and "#9" back to back on the same chord.
  3. Lydian vs. IonianSet up →
    The drone alternates maj7#11 and plain maj7. Play Lydian over the #11 chords — the raised 11 is a color tone you can sit on. Play Ionian over the plain maj7 chords, where the natural 11 is an avoid note: lean on it briefly to hear the clash, then resolve off it. Same chord family, two different jobs for the 11.
  4. b13 vs. natural 13Set up →
    Same comparison, for the top tension this time.
  5. Stacked altered tensionsSet up →
    b9, #9, and #11 together over a dominant chord for a full "altered" sound.
  6. Complex/unusual tensions onSet up →
    Check "Include complex/unusual tensions" and let genuinely rare combinations surprise your ear.
  7. Resolve the dominantSet up →
    Sets Resolve Dominants → Major, so the drone alternates a real dominant with its actual tonic. Sing or play where each dominant wants to go before it lands — try → Minor too.
  8. Maj7#11 in isolationSet up →
    Major 7th plus #11 only — the classic "Lydian" comping color, drilled on its own.
  9. Minor 9/11 in isolationSet up →
    Minor 7th with natural 9 and 11 — the Dorian-flavored minor sound, isolated from the rest.
  10. Full altered-dominant vocabularySet up →
    Dominant quality, every tension box checked — comp or solo through the "everything's available" sound.

For once the individual pieces above aren't the hard part.

  1. Everything onSet up →
    Every root, every quality, every tension — react to whatever comes with zero preparation.
  2. Fast reflex, eyes closedSet up →
    Everything on, eyes closed — react purely by ear and feel.
  3. Name it before you play itSet up →
    Everything on — call out the quality out loud before your first note.
  4. One-note reactionSet up →
    Everything on, but only one note allowed per chord: the first thing your ear finds.
  5. No repeatsSet up →
    Chaos setting, but you're not allowed to play the same lick twice across the whole session.
  6. Quick-comp reflexSet up →
    Everything on — comp just one stab per chord, as fast and clean as you can.
  7. Tempo-pushed chaosSet up →
    Chaos setting, fast Metronome tempo, Keys sound so nothing gets lost in a swell — the hardest combination the tool can produce.
  8. Chaos with a fixed target toneSet up →
    Everything on, but you must always resolve to one chosen note (like the tonic) no matter what hits.

Treating the drone as a writing tool, not just a drill.

  1. Steal a progressionSet up →
    Freeze on a chord you like, note it down, and build the next few by ear like writing a tune.
  2. Play as melodically as possibleSet up →
    Focus entirely on note selection over the changes — no runs, no licks, just the most singable line you can find.
  3. Transcribe-style dictationSet up →
    Freeze a chord and work out its structure by ear — root, 3rd, 5th, 7th as intervals, not absolute note names — then confirm the actual spelling with Show Chords.
  4. Slow-motion voicing studySet up →
    Long duration, one chord — try three totally different voicings for the same symbol and compare them.
  5. Answering-machine gameSet up →
    Treat each new chord as a question a bandmate just asked, and answer it compositionally before it changes.
  6. Two-chord vamp songwritingSet up →
    Clear roots down to two, one quality, and write a short original idea over just that loop.

Playing a role, not just playing notes.

  1. Trade foursSet up →
    Every chord change, alternate between comping for four "bars" and soloing for four.
  2. Rhythm-section lockSet up →
    Metronome mode — comp exactly with the click, as if a drummer were depending on your time.
  3. Vocalist simulationSet up →
    Sing a simple melody over the changing chords as if you were the singer, guitar silent.
  4. Duo compingSet up →
    Alternate chords between two different voicings or registers, as if trading comping duties with a second guitarist.
  5. Feature-the-bass drillSet up →
    Solo using only the lowest strings/frets available, simulating a bass feature.
  6. Listening-only roundSet up →
    Let a full cycle play through without playing anything — pure ear training for what a bandmate might do.
  7. Live-arranging simulationSet up →
    Decide in real time whether each new chord wants comping, soloing, or silence from you, like reading a bandstand.
